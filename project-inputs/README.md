# 📂 Project Inputs

Drop your project files here.  
Claude reads this folder to understand your project.


---


## 1.0 ✅ Supported file types


Any file Claude can read:

- 📄 PDFs, Word docs, text files

- 📊 Spreadsheets (Excel, CSV)

- 🖼️ Images (PNG, JPG, SVG)

- 🔤 Markup (Markdown, HTML, JSON, YAML, XML)

- 💻 Code files (any language)

- 📽️ Presentations (PPTX)


---


## 2.0 💡 Tips

- Use clear filenames — e.g. `brand-guidelines.pdf`, `sitemap-v2.xlsx`
- You can add files at any point during the project
- No need to organize into subfolders — flat is fine
- Claude will reference these documents throughout the project
